# AI Shirt Club Landing

Premium one-page waitlist site for AI Shirt Club, built with React, Vite, and Tailwind CSS.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deploy on Vercel

- Framework preset: Vite
- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `dist`

No backend services or environment variables are required.
